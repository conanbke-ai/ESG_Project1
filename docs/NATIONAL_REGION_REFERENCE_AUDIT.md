# 전국 설비 행정구역 기준정보 감사

검증일: 2026-08-31 (Asia/Seoul)

## 적용 결과

전국 설비의 건수·용량은 EPSIS 원본을 사실 테이블로 유지하고, 화면에서 사용하는 행정구역명은
별도의 유효일 기준정보로 표준화한다. 현재 기준정보는
[`config/administrative_regions_20260701.json`](../config/administrative_regions_20260701.json)이며,
[행정안전부 행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do)의
2026-07-01 변경을 기준으로 한다.

- 원본 합계: 188,594개 등록 레코드, 33,059.516180 MW
- 광역 기준: 16개
- 원본 세부지역 표기: 320개
- 표준 세부지역 집계: 258개
- 좌표 캐시 정확 일치 집계: 249개
- 시도 중심좌표 대체: 9개(미해결 격리 4개 포함)
- 광역지역·세부지역 원본 충돌: 51개 원본 행, 53.289725 MW
- 공식 근거를 검토해 확정한 raw-row override: 47개 원본 행, 48.895470 MW
- 미해결 격리: 4개 원본 행, 4.394255 MW

총 건수와 용량은 표준화 전후에 동일하다. `광주`, `광주광역시`, `전남`, `전라남도`와 이미
새 명칭으로 들어온 값을 `전남광주통합특별시`로 합치지만, Bronze CSV의 원문은 변경하지 않는다.
EPSIS 기준일 2026-08-05가 행정구역 변경 시행일보다 뒤인데도 `광역지역`과 `세부지역`의 갱신
속도가 달라 생긴 혼합 표기를 유효일 기준 reference로 해소한 것이다. 이 명칭 통합은 2026-07-01
공식 표기 원칙을 적용하는 작업이며, 충돌 행의 실제 소속을 이름만으로 추정하는 규칙은 아니다.

## 검토 override와 격리 계약

검토 기준은
[`config/national_solar_location_overrides_20260828.json`](../config/national_solar_location_overrides_20260828.json)에
보관한다. 원본 충돌 51행 가운데 공식 주소·좌표 등 검토 근거로 소속을 확정할 수 있는 47행에만
raw-row override를 적용한다. 나머지 4행은 원본 광역지역 합계를 유지하되, 서로 다른 시도의
세부지역명이 그 아래 노출되지 않도록 각 광역권의 `미확정 지역`으로 묶고 `공식 주소 미확인`으로
표시한다.
Override와 격리는 Bronze 원문을 수정하지 않으며, 전국 원본 합계 188,594개·33,059.516180 MW도
바꾸지 않는다.

이 기준정보는 대상 EPSIS 원본의 SHA-256에 결합한다. 각 검토 그룹에는 기대 원본 행 수와 기대
설비용량 합계, 근거 URL, 판정 방법, 신뢰도와 사유를 함께 둔다. 원본 SHA-256, 그룹별 행 수 또는
용량 합계가 하나라도 기대값과 다르면 override 일부만 적용하거나 기존 결과를 재사용하지 않고
대시보드 생성을 중단한다. 새 원본에는 같은 판단을 자동 이월하지 않고 다시 검토한다.

공식 자료를 다시 검색해도 주소를 한 곳으로 확정하지 못한 행은 다음과 같다.

| ---: | --- | ---: | --- | --- | --- |
| 23,255 | 금성태양광 | 1.200000 | 전남 / 충청남도 금산군 | 전남·광주 미확정 지역 | 공식 허가주소와 유일 일치하지 않음 |

주소 또는 좌표가 유일하게 연결될 때만 검토 override에 편입한다.

## 현재 파일의 역할과 한계

| 파일 | 역할 | 판단 |
| --- | --- | --- |
| `한국전력거래소_[전국] 태양광발전설비현황_20260828.csv` | 등록건수·용량 사실 원천 | 전국 집계 기준. 주소·좌표·공식 설비 ID는 없음 |
| `HOME_발전설비_발전기별.xlsx` | 과거 EPSIS 계열 보조 원본 | 같은 11개 컬럼과 같은 지역 오류를 포함해 독립 교정 근거가 아님 |
| `map/json/coord_cache.json` | EPSIS 세부지역 표시 좌표 보조 | 과거 Kakao 지오코딩 캐시. 687키 중 1개 좌표 오류와 오염 키가 있어 행정 master로 사용 금지 |
| `file/KMA_data_file/META_관측지점정보.csv` | 기상관측소 위치 | 울릉도 지점 115의 주소·좌표를 확인할 수 있지만 전국 행정구역 master는 아님 |
| `file/standardized/plant_registry.csv` | 확보한 학습 발전소 매핑 | 68개 자산 전용. 전국 EPSIS 등록설비를 채우는 용도로 사용 금지 |
| `map/json/geoJson.json` | 공식 시도 표시 경계 | SGIS 2025년 2분기 시도 경계를 WGS84로 변환. source hash·기준일·도서 소속 회귀검사 포함 |

런타임 지도는 Google이 아니라 OpenStreetMap 배경 타일과 공식 SGIS 경계를 사용한다. 배경지도
라벨은 시각적 참고일 뿐 집계 키로 사용하지 않는다. SGIS의 2025년 2분기 17개 시도 Shapefile을
EPSG:4326으로 변환하고, 150m topology-preserving 단순화와 원본 archive·Shapefile SHA-256을
GeoJSON metadata에 남긴다. 구 경계의 `KR29`와 `KR46`은 같은 최신 행정구역명으로 연결해
선택·색상·통계를 일치시킨다.

기존 SimpleMaps 경계는 백령도·대청도·연평도와 강화도권 일부를 `KR41` 경기도 polygon에 넣어
옹진군 통계가 정상이어도 지도 hover가 경기로 보였다. 새 게시 검사는 백령도·대청도·연평도가
`KR28` 인천, 울릉도가 `KR47` 경북에 오직 한 번 포함되는지 확인한다. 자연지명 검색 별칭은
행정구역 탐색에만 쓰며 EPSIS 발전기 행을 이름만으로 재배정하지 않는다.

## 울릉·독도 판단

좌표 캐시에는 `경상북도 울릉군`, KMA 메타데이터에는
`경상북도 울릉군 울릉읍 도동리`가 존재한다. 따라서 공식 지역명과 지도 위치를 확인하는 근거는
있다. 그러나 최신 EPSIS `세부지역`에는 `울릉군` 또는 `독도`가 0건이다.

발전기명에 `울릉`·`독도`가 포함된 6개 행은 EPSIS 원문상 안동시·원주시·부여군·경산시로
등록돼 있다. 발전기명만 보고 울릉군으로 옮기면 공식 합계를 임의 변경하므로 자동 재배정하지
않는다. 공식 주소나 좌표로 유일하게 확인될 때만 reviewed override를 만들고, 그 전에는 원본 광역
합계와 `공식 주소 미확인` 상태를 유지한다.

## 공식 기준정보 수집 방향

행정구역 명칭·코드는 [행정안전부 법정동 전체자료](https://www.code.go.kr/stdcode/regCodeL.do)와
[국토교통부 전국 법정동 CSV](https://www.data.go.kr/data/15063424/fileData.do)를 정기
스냅샷으로 저장한다. 좌표가 확보된 행은
[국토교통부 행정구역도 WMS/WFS](https://www.data.go.kr/data/15059008/openapi.do)의 시도·시군구·
읍면동·리 경계를 한 번 내려받아 GeoParquet으로 변환한 뒤 로컬 point-in-polygon으로 결합한다.
18만 건을 건별 API로 호출하지 않는다.

발전소 주소·좌표를 보강하는 전국 1순위 후보는
[전국태양광발전소전기사업허가정보표준데이터](https://www.data.go.kr/data/15107742/standard.do)다.
발전시설명, 주소, 위경도, 용량, 가동상태, 허가·설치 정보를 제공하지만 EPSIS와 공유하는 설비
고유키나 사업자명이 없다. 다음 조건을 모두 만족할 때만 자동 교정을 허용한다.

1. 정규화한 발전소명이 정확히 일치한다.
2. 용량 허용오차 안의 후보가 전국에서 한 건뿐이다.
3. 주소 또는 좌표가 비어 있지 않다.
4. 좌표와 공식 경계의 행정구역이 주소와 일치한다.

동명 후보, 마스킹 이름, 주소·좌표 결측은 `ambiguous` 또는 `unresolved`로 격리한다. 발전공기업
자체 좌표, 지자체 원시 허가번호·설치주소, 전국 표준 유일 일치 순으로 근거 우선순위를 둔다.
각 교정에는 `source_url`, `source_date`, `match_method`, `confidence`, `old_region`,
`new_region`을 남긴다.

권장 저장 구조는 다음과 같다.

```text
reference/administrative/region_dimension.parquet
reference/administrative/region_alias.parquet
reference/administrative/boundaries/*.parquet
reference/solar_permits/permit_snapshot_YYYYMMDD.parquet
file/standardized/plant_location_mapping.parquet
```

`region_dimension`은 법정동코드와 명칭·시행일·폐지일을, `region_alias`는 과거명·축약명·자연지명
검색어를, `plant_location_mapping`은 원본 주소·좌표와 결정 코드·근거·품질상태를 보관한다.
울릉도 같은 자연지명은 검색 별칭으로 `경상북도 울릉군`에 연결하되, EPSIS 설비가 없으면 0건인
지역 reference와 설비 fact를 섞지 않는다.

수동 발전소 별칭·Kakao 좌표 캐시·legacy ASOS seed를 공식 자료로 대체할 수 있는 범위와 안전한
승인 조건은 [`OFFICIAL_SOURCE_REPLACEMENT_AUDIT.md`](OFFICIAL_SOURCE_REPLACEMENT_AUDIT.md)에
기록했다.

## 검색 화면 안정화

검색 결과는 고정 높이 내부 스크롤 영역에서 갱신한다. 검색 전후 요약 영역 높이를 유지하고,
검색 중에는 결과 등록건수·용량 합계를 같은 자리에 표시한다. 한글 IME 조합 중에는 결과를 다시
그리지 않고 조합 종료 뒤 `requestAnimationFrame`에서 한 번만 갱신한다. 결과가 0건과 수십 건
사이를 오가더라도 문서 높이·검색창 위치·포커스가 변하지 않아야 한다.
